# 내레이션 녹음

`narration.m4a`(대표님 녹음)를 이 폴더에 두면 `npm run render` 가 목소리를 넣은 영상을 만듭니다.
공개 저장소라 녹음 파일은 올리지 않았습니다. 파일이 없으면 음악만 들어간 영상이 만들어집니다.

- 파일 이름·경로: `config.js` → `voice.file`
- 문장 구간 찾기: `npm run voice:scan` → 말소리 구간(초)이 출력됩니다. 각 장면의 `voice.from / to` 에 옮겨 적으세요.
- 폰 녹음(m4a)·mp3·wav 모두 됩니다. 조용한 방에서, 문장 사이를 1초쯤 띄워 읽으면 자르기 쉽습니다.

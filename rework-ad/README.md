# RE:WORK STUDIO — 15초 광고 영상 (인스타 릴스 · 메타 광고)

**결과물**: [`out/rework_ad_15s_9x16.mp4`](out/rework_ad_15s_9x16.mp4)
1080×1920 (9:16) · 30fps · 정확히 15.00초 (450프레임) · H.264 High · AAC 48kHz 스테레오 · -16 LUFS

![스토리보드](out/storyboard.png)

HTML/CSS/JS 로 만든 애니메이션을 헤드리스 Chromium 에서 프레임 단위(0~449)로 캡처해 ffmpeg 로 인코딩합니다.
화면은 프레임 번호만으로 결정되고(시간·랜덤에 의존하지 않음) BGM·효과음도 코드로 합성하므로, 몇 번을 렌더해도 같은 결과가 나옵니다.

## 사용법

```bash
cd rework-ad
npm install
npx playwright install chromium   # 처음 한 번만 (헤드리스 브라우저)
npm run render                    # 검사 → BGM 합성 → 450프레임 캡처 → mp4
```

| 명령 | 하는 일 |
|---|---|
| `npm run render` | 검사를 통과하면 `out/rework_ad_15s_9x16.mp4` + `out/contact_sheet.png`(0.5초 간격 30컷) 생성 |
| `npm run check` | 문장 노출 시간(1.2초 이상)과 인스타 UI 영역 침범 여부만 검사 |
| `npm run stills` | 주요 장면 9컷(`out/stills/`) + 스토리보드 이미지(`out/storyboard.png`) |
| `npm run preview` | 브라우저 미리보기: 재생·탐색·인스타 UI 영역 표시. config.js 를 고치고 새로고침하면 바로 반영 |
| `npm run audio` | BGM 만 다시 합성 (`out/audio.wav`) |

## 문구·타이밍·컬러 바꾸기: `config.js` 한 파일만 고치면 됩니다

- **문구**: `scenes` 안의 `text`, `lines`, `headline`, `steps`, `slogan`, `button`, `url`, 알림 문구 등. 줄바꿈은 배열로 나눠 적습니다.
- **강조 표기**: `[단어]` 는 빨간 대괄호(랜딩 히어로의 `[스토리]`와 같은 스타일), `{단어}` 는 빨간 밑줄입니다.
- **타이밍**: 모두 초 단위입니다. 각 장면은 다음 장면의 `start` 에서 끝납니다. BGM 이 120BPM(1박 = 0.5초)이라 0.25초 단위로 맞추면 박자에 붙습니다.
- **컬러**: `colors.ink / cream / red`. 화면의 모든 색은 이 3색과 그 투명도로만 만들어집니다.
- **소리**: `audio.loudness`(LUFS), `audio.volume`, `audio.sfx`(효과음 켜고 끄기).

문구가 길어지면 폭에 맞게 글자 크기가 자동으로 줄어듭니다. 문장 노출이 1.2초보다 짧아지거나 핵심 텍스트가 상단 250px·하단 350px(인스타 UI 영역)을 침범하면 렌더를 멈추고 어느 문장이 문제인지 알려줍니다(`--force` 로 강제 진행 가능).
타이핑 소리·전환 효과음·4단계 벨은 화면 타이밍을 그대로 따라가므로 따로 맞출 필요가 없습니다.

## 스토리보드 (30fps, 120BPM에서 1박 = 15프레임)

광고 구조는 **후킹 → 공감 3연타 → 전환(안도) → 신뢰 → 제안 → CTA**입니다.

| 시간 | 장면 | 화면 | 자막 (한 화면 한 문장) |
|---|---|---|---|
| 0.0–2.5s | ① 후킹 | 블랙. 업무 알림이 쌓이는 동안 'SNS 게시물 올리기' 알림만 '다시 알림' → '3일째 미룸'으로 계속 밀림 | 혼자 사업하는 대표님, / SNS는 늘 뒷전이죠? (첫 프레임부터 보임) |
| 2.5–4.0s | ② 공감 | 게시물 작성 화면. 타이핑(ㅁ→뭐 조합) → 커서 깜빡임 → 백스페이스로 지움 | 뭐부터 올리지? |
| 4.0–5.6s | ② 공감 | 입력창 클로즈업 컷. 빠른 타이핑 → 전체 선택 → 삭제 → 커서가 남았다 사라짐 | 컨셉은? / 스토리는? |
| 5.6–7.0s | ② 공감 | 올린 게시물. 조회수가 12→37에서 멈춤 | 올려도… 반응은 조용하고 |
| 7.0–7.4s | ③ 전환 | 비비드 레드 라인이 문장을 가르고, 검은 화면이 위아래로 갈라지며 크림 배경 | — |
| 7.3–10.0s | ③ 안도 | 레드 라인이 구분선으로 자리 잡고, ②에서 고민하던 질문들이 체크리스트로 돌아와 박자마다 빨간 체크 + 오르는 벨 | 혼자 애쓰지 마세요, / 같이 정리해드릴게요 · ☑ 뭐부터 올릴지 ☑ 컨셉 ☑ 스토리 |
| 10.0–11.5s | ④ 신뢰 | 하드컷. 커다란 **1:1** (콜론은 로고와 같은 빨간 박스) | 처음부터 끝까지, / 대표가 직접 함께해요 |
| 11.5–13.0s | ④ 제안 | 하드컷. '제대로 세팅'에 빨간 밑줄 | 올해가 가기 전에, / 내 SNS 제대로 세팅 |
| 13.0–15.0s | ⑤ CTA | 로고(`RE`+빨간 박스 속 `:`+`WORK STUDIO`), 빨간 **무료 상담하기 →** 버튼(살짝 눌림), 주소 | 상담만 받아도 괜찮아요 · rework-studio.vercel.app |

**카피 설계**
- **후킹**
  - 첫 프레임(썸네일)부터 타깃을 직접 부릅니다("혼자 사업하는 대표님,").
  - 바로 이어지는 "SNS는 늘 뒷전이죠?"는 계속 미뤄지는 SNS 알림과 짝을 이룹니다. "어, 딱 내 얘기네"를 노린 장면입니다.
- **공감 3연타**: 무엇을 올릴지, 컨셉·스토리, 올려도 조용한 반응. 막막함을 구체적인 장면으로 보여줍니다.
- **전환·안도**
  - 핵심 정서인 "혼자 애쓰지 마세요, 같이 정리해드릴게요"를 한 문장으로 보여줍니다.
  - 앞에서 쓰다 지운 질문들이 체크되며 정리되는 콜백으로 해결을 눈으로 보여줍니다.
- **신뢰 → 제안 → CTA**
  - '1:1'과 '처음부터 끝까지 대표가 직접'은 랜딩 페이지에 있는 사실입니다.
  - 올해 안에 해보자는 부드러운 제안은 재촉하지 않는 톤으로 썼습니다.
  - 버튼 아래 "상담만 받아도 괜찮아요"는 랜딩의 "상담은 무료이며 계약으로 이어지지 않습니다"를 근거로 한 안심 문구입니다.
- **소리 없이 봐도 이해되게**: 모든 내용을 화면 문장으로 전달합니다.

**톤과 사운드**
- **화면**
  - 전반부는 블랙 배경의 UI(알림·입력창·조회수)만 있는 답답한 화면입니다.
  - 레드는 7초 전까지 쓰지 않고, 레드 라인이 처음 등장하는 순간이 전환입니다.
  - 이후 크림 배경과 구분선, 체크리스트가 '정돈'을 표현합니다.
- **사운드**
  - 0~7초: A단조 미니멀. 시계 틱, 낮은 펄스, 필터가 서서히 열리는 패드, 작은 타이핑 소리, 라이저
  - 7초~: A장조로 밝아짐. 킥·클랩·셰이커, 플럭 아르페지오
  - 체크될 때마다 오르는 벨이 울리고, CTA 등장 때 차임이 나옵니다. 마지막은 으뜸화음으로 끝납니다.

## 브랜드 근거: 랜딩 페이지 https://rework-studio.vercel.app

| 항목 | 랜딩 페이지 | 영상 |
|---|---|---|
| 컬러 | `--ink #0f0f0f` · `--canvas #f3efe4` · `--primary #ff2d2d` | 동일 (기획서 3색과 일치) |
| 폰트 | Pretendard Variable (본문), IBM Plex Mono (작은 라벨) | Pretendard 만 사용 (고딕 계열만 규칙) |
| 로고 | `RE` + 빨간 박스 안 `:` + `WORK` + 흐린 `STUDIO` | 같은 비율로 재현. 1:1 장면의 콜론도 같은 빨간 박스 |
| 브랜드 표기 | 히어로 `● RE:WORK STUDIO — CONTENT BRANDING` | 전환 이후 화면 상단에 계속 표시 |
| 사실 근거 | "1:1 · 전 과정 대표 직접 진행", "상담은 무료이며 계약으로 이어지지 않습니다" | 신뢰 장면, CTA 안심 문구 |
| CTA | 무료 상담 신청 (`/consult`) | 무료 상담하기 |

**영상에 들어간 숫자에 대해**: 조회수(12→37)·알림 개수 같은 숫자는 타깃(대표님)의 상황을 보여주는 연출용 UI입니다. 리워크의 성과나 실적 수치는 영상에 넣지 않았습니다(`config.js` 의 `struggle.post.views` 에서 바꿀 수 있습니다).

## 구조

```
rework-ad/
├─ config.js            ← 문구·타이밍·컬러·사운드 (여기만 고치면 됨)
├─ src/
│  ├─ index.html        1080×1920 합성 화면 (?frame=120 · ?debug=1 로 인스타 UI 영역 표시)
│  ├─ main.js           장면 + 키네틱 타이포 (renderFrame(f) = 프레임 번호만으로 화면 결정)
│  ├─ timeline.js       config(초) → 프레임 타임라인, 노출 시간 검사 (영상·오디오 공용)
│  ├─ styles.css        레이아웃 · 타이포 · 3색 토큰
│  ├─ lib.js, icons.js  이징·글자 맞춤·선 아이콘
│  └─ preview.html      미리보기 플레이어
├─ scripts/
│  ├─ render.mjs        검사 → 오디오 → 캡처 → ffmpeg(BT.709) → 결과 검증
│  ├─ audio.mjs         BGM·효과음 합성, BS.1770 라우드니스 맞춤, 피크 리미터
│  ├─ preview.mjs       미리보기 서버
│  └─ server.mjs        로컬 정적 서버
└─ out/                 mp4 · 스토리보드 · 컨택트 시트
```

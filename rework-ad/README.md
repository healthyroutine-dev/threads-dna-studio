# RE:WORK STUDIO — 15초 광고 영상 (인스타 릴스 · 메타 광고)

**결과물**
- `out/rework_ad_15s_9x16.mp4`: 대표님 내레이션 + 음악 (메인)
- [`out/rework_ad_15s_9x16_music_only.mp4`](out/rework_ad_15s_9x16_music_only.mp4): 같은 화면에 음악만 (A/B 테스트용)

두 파일 모두 1080×1920 (9:16) · 30fps · 정확히 15.00초 (450프레임) · H.264 High · AAC 48kHz 스테레오 · -14 LUFS 입니다.

> 공개 저장소라 대표님 녹음 원본(`voice/narration.m4a`)과 목소리가 들어간 메인 영상은 올리지 않았습니다.
> 녹음을 `voice/` 에 두고 `npm run render` 하면 두 파일이 함께 만들어집니다. 녹음이 없으면 음악만 들어간 영상이 만들어집니다.

![스토리보드](out/storyboard.png)

HTML/CSS/JS 로 만든 애니메이션을 헤드리스 Chromium 에서 프레임 단위(0~449)로 캡처해 ffmpeg 로 인코딩합니다.
- 화면은 프레임 번호만으로 결정됩니다(시간·랜덤에 의존하지 않음).
- BGM·효과음은 코드로 합성하고, 목소리는 녹음에서 문장 단위로 잘라 장면에 맞춰 놓습니다.
- 그래서 몇 번을 렌더해도 같은 결과가 나옵니다.

## 사용법

```bash
cd rework-ad
npm install
npx playwright install chromium   # 처음 한 번만 (헤드리스 브라우저)
npm run render                    # 검사 → 목소리 다듬기·음악 합성·믹스 → 450프레임 캡처 → mp4 두 개
```

| 명령 | 하는 일 |
|---|---|
| `npm run render` | 검사를 통과하면 메인 mp4 + 음악만 mp4 + `out/contact_sheet.png`(0.5초 간격 30컷) |
| `npm run check` | 문장 노출 시간(1.2초 이상), 내레이션 배치(겹침·장면 넘침), 인스타 UI 영역 침범만 검사 |
| `npm run stills` | 주요 장면 10컷(`out/stills/`) + 스토리보드 이미지(`out/storyboard.png`) |
| `npm run preview` | 브라우저 미리보기: 재생·탐색·인스타 UI 영역 표시 (목소리 포함) |
| `npm run audio` | 소리만 다시 만들기 (`out/audio.wav`) + 문장별 목소리/음악 비율 출력 |
| `npm run voice:scan` | 녹음에서 말소리 구간(초)을 찾아 출력 (새로 녹음했을 때 `from/to` 고르기) |

## 문구·타이밍·목소리·컬러 바꾸기: `config.js` 한 파일만 고치면 됩니다

- **자막**
  - `scenes` 안의 `text` 입니다. 녹음에서 실제로 말한 문장과 같게 맞춥니다.
  - 줄바꿈은 배열로 나눠 적습니다.
- **목소리**
  - 장면마다 `voice: { from, to, delay }` 를 적습니다.
  - `from~to` 는 원본 녹음에서 잘라 쓸 구간(초)입니다.
  - `delay` 는 장면이 시작하고 몇 초 뒤에 말이 시작할지입니다.
  - 녹음을 새로 하면 `npm run voice:scan` 으로 구간을 찾아 옮겨 적습니다.
- **말에 맞춘 움직임**: 모두 그 문장 음성이 시작한 뒤의 초입니다.
  - `punch.wordAt`: 단어마다 쾅
  - `cause.zoomAt`: '수익화'에서 줌
  - `cta.buttonAt / noteAt / pressAt / urlAt`: 버튼 등장, 안심 문구, '신청해'에서 버튼 눌림, 주소
- **정곡 장면 지출 목록**: `punch.more` 입니다.
  - 화면에만 나오고 말하지는 않습니다.
  - 아래에서 하나씩 올라오며 위로 스크롤되고, 맨 아래는 흐려지며 ⌄ 가 '더 있음'을 보여줍니다.
- **강조 표기**: `{단어}` 는 빨간 밑줄입니다. 'SNS' 밑줄은 화면을 가른 레드 라인이 그대로 내려앉은 것입니다.
- **타이밍**
  - 모두 초 단위입니다. 각 장면은 다음 장면의 `start` 에서 끝납니다.
  - 음악의 스톱타임·드롭·브레이크다운·빌드업도 장면 시작 시간을 따라갑니다.
  - 드롭(6.3초) 이후 장면은 0.5초(1박) 단위로 두면 박자에 붙습니다.
- **소리**
  - 음량: `audio.loudness`(최종 LUFS), `voice.loudness`(목소리), `voice.music`(목소리 버전의 음악)
  - 덕킹: `voice.duck` 은 말하는 동안 음악을 줄이는 양입니다.
  - 효과음: `audio.sfx` 에서 켜고 끕니다.
  - `voice.enabled: false` 면 목소리 없이 만듭니다.
- **컬러**: `colors.ink / cream / red`. 화면의 모든 색은 이 3색과 그 투명도로만 만들어집니다.

렌더 전에 자동으로 검사하고, 문제가 있으면 렌더를 멈추고 어느 문장이 문제인지 알려줍니다(`--force` 로 강제 진행 가능).
- 문장 노출이 1.2초보다 짧아지는 경우
- 핵심 텍스트가 상단 250px·하단 350px(인스타 UI 영역)을 침범하는 경우
- 목소리가 다음 장면까지 넘어가거나 앞 문장과 겹치는 경우

문구가 길어지면 폭에 맞게 글자 크기가 자동으로 줄어듭니다.

## 스토리보드 (30fps, 120BPM에서 1박 = 15프레임)

**앞 5초 안에 후킹 → 돈 얘기 → '수익화'까지 말로 찌르고, 6.3초 드롭에서 답(SNS)과 브랜드가 나옵니다.**
자막 = 내레이션 그대로라 소리를 꺼도 같은 이야기가 전달됩니다.

| 시간 | 장면 | 내레이션 = 자막 | 화면 (계속 움직임) | 소리 |
|---|---|---|---|---|
| 0.0–2.3s | ① 후킹 | 언제까지 배우기만 하실 거예요? | 블랙. 강의·자격증·챌린지 결제 알림이 폭포처럼 쌓임 (첫 프레임부터) | 0초 임팩트, 결제음, A단조 인트로 |
| 2.3–4.57s | ① 정곡 | 강의에 얼마, 자격증에 얼마, | 음악이 멈추고, 말하는 단어마다 거대한 글자가 쾅. 이어 '프로그램 구입에 얼마, 장비 세팅에 얼마, …'가 아래에서 계속 올라오고 ⌄ 로 '더 있음' | 스톱타임 + 단어마다 타격음, 목록 한 줄마다 '띵' |
| 4.57–6.3s | ① 원인 | 이제 수익화 하셔야죠. | 휩팬으로 내 계정 → '수익화'라고 말하는 순간 '게시물 0' 으로 줌 펀치 | 휩, 드롭 박자에 맞춘 킥·스네어 롤·라이저 |
| 6.3–8.3s | ② 답 | SNS 시작하세요. | **드롭.** 레드 라인이 화면을 가르고 크림으로. 라인이 'SNS' 밑줄로 내려앉음. 상단에 `● RE:WORK STUDIO` + `[무료 상담 →]` | A장조 드롭 (임팩트가 먼저, 바로 뒤에 목소리) |
| 8.3–10.3s | ③ 보여주기 | 제가 1:1로 도와드릴게요. | 같은 계정이 정리되며 채워짐: 소개글·하이라이트, 게시물 타일이 박자마다 톡톡 (0 → 6) | 하우스 그루브, 타일마다 플럭 |
| 10.3–12.3s | ④ 마음 | 이제 충분히 배우셨어요. | 결제했던 강의 카드들이 가지런히 쌓이고 하나씩 빨간 '수강 완료' 도장 → 끝에 위로 날아감 | 브레이크다운 (드럼 빠짐), 도장 소리 → 한 박 빌드업 |
| 12.3–15.0s | ⑤ CTA | 무료 상담 편하게 신청해 보세요. | 로고가 꽝 → '상담'에서 **무료 상담하기 →** 버튼 → '신청해'에서 버튼 눌림 → 안심 문구 → 주소 | CTA 드롭 + 차임 → 으뜸화음 |

## 내레이션 편집

녹음(23.3초, 9문장)은 말소리만 약 17초라 15초에 전부 넣으면 1.2배속 이상이 되어 부자연스럽습니다. 그래서 이렇게 편집했습니다.
- 말 속도는 원래대로 두었습니다.
- 흐름이 가장 강한 7문장을 썼습니다.
- 문장 사이 쉼·숨소리는 잘라 0.2~0.3초로 맞췄습니다.

| 녹음 문장 | 사용 |
|---|---|
| 언제까지 배우기만 하실 거예요? | ① 후킹 |
| 강의에 얼마, 자격증에 얼마? | ① 정곡 (자막은 목록이 이어지므로 '얼마,') |
| 이제 수익화 하셔야죠. | ① 원인 |
| SNS 시작하세요. | ② 답 |
| 제가 1:1로 도와드릴게요. | ③ 보여주기 |
| 이제 충분히 배우셨어요. | ④ 마음 |
| 올해가 가기 전에 SNS 세팅부터 시작하세요. | 뺌. '답'과 겹치고, 넣으면 15초를 넘음 |
| 나도 한번 이런 생각이 든다면 | 뺌. 시간이 모자라 CTA 는 뒤 문장만 사용 |
| 무료 상담 편하게 신청해 보세요. | ⑤ CTA |

빠진 문장을 쓰려면 원하는 장면의 `voice.from / to` 를 바꾸고 자막 `text` 를 그 문장으로 고치면 됩니다. `npm run check` 가 길이가 맞는지 알려줍니다.

**목소리 다듬기 (`scripts/voice.mjs`)**

값은 녹음을 일반 말소리 평균 스펙트럼(LTASS)과 비교해 정했습니다.

| 처리 | 설정 | 측정한 이유 |
|---|---|---|
| 저역 컷 | 85Hz | 63Hz 대역이 말소리 기준보다 16dB 많음 (바닥 울림) |
| 명료도 | +3.5dB @2.2kHz | 1.2~3kHz 가 4~6dB 부족 |
| 치찰음 | -3dB @9kHz + 디에서 | 8~10kHz 가 4~5dB 많음 |
| 말끝 보정 | 작게 사라지는 말끝을 최대 +8dB | '거예요?'가 문장 앞부분보다 19dB 작음 |
| 컴프레서 | 3:1 | 문장 안 크기 차이를 줄임 |
| 마무리 | EQ + 피크 리미터 | 압축 후 밝아진 고음을 정리하고, 순간 피크를 눌러 믹스에서 음악이 출렁이지 않게 |

**믹스**
- 말하는 동안 음악을 8dB 내립니다. 말이 시작되기 0.05초 전부터 비켜 줍니다.
- 킥·베이스(180Hz 아래)는 절반만 내려 리듬은 살렸습니다.
- 결과: 문장마다 목소리가 음악보다 9~13 LU 위에 있어, 폰 스피커에서도 또렷합니다.
- 결제음은 목소리와 같은 2kHz 대역이라 목소리 버전에선 작게 넣었습니다.

## 카피

- **정곡**
  - "언제까지 배우기만 하실 거예요?"로 멈추게 합니다.
  - "강의에 얼마, 자격증에 얼마"로 배우는 데 쓴 돈을 찌르고, 이어서 지출 목록이 끝없이 올라옵니다.
  - "이제 수익화 하셔야죠"에서 비어 있는 내 계정(게시물 0)으로 원인을 보여줍니다.
- **답**: "SNS 시작하세요." 드롭과 함께 레드 라인이 'SNS' 밑줄이 됩니다.
- **증명**: 비어 있던 같은 계정이 정리되는 전후를 보여줍니다. 팔로워 수는 그대로 두어 성과를 과장하지 않습니다.
- **마음**
  - "이제 충분히 배우셨어요"는 더 배워야 한다는 불안을 내려놓게 하는 문장입니다.
  - 랜딩의 "당신의 전문성은 이미 충분합니다"와 같은 메시지입니다.
- **CTA**
  - "무료 상담 편하게 신청해 보세요" + 버튼 아래 안심 문구 "상담만 받아도 괜찮아요"
  - 안심 문구의 근거는 랜딩의 "상담은 무료이며 계약으로 이어지지 않습니다" 입니다.
- **메타 광고 정책**
  - 보는 사람의 행동(배우기만 함)을 말할 뿐, 재정 상태를 단정하지 않습니다.
  - "돈 없으시죠?" 같은 문구는 개인 특성 정책에 걸릴 수 있어 피했습니다.

**영상에 들어간 숫자에 대해**
- 결제 금액, 지출 목록, 게시물 수(0 → 6), 팔로워 수는 타깃의 상황과 계정 정리를 보여주는 연출용 UI 입니다.
- 리워크의 성과나 실적 수치는 영상에 넣지 않았습니다. `config.js` 의 `payments`, `punch.more`, `profile` 에서 바꾸거나 뺄 수 있습니다.

## 구조

```
rework-ad/
├─ config.js            ← 문구·타이밍·목소리 구간·컬러·사운드 (여기만 고치면 됨)
├─ voice/               대표님 녹음 (narration.m4a — 저장소에는 올리지 않음)
├─ src/
│  ├─ index.html        1080×1920 합성 화면 (?frame=120 · ?debug=1 로 인스타 UI 영역 표시)
│  ├─ main.js           장면 + 키네틱 타이포 (renderFrame(f) = 프레임 번호만으로 화면 결정)
│  ├─ timeline.js       config(초) → 프레임 타임라인, 내레이션 배치, 노출·배치 검사 (영상·오디오 공용)
│  ├─ styles.css        레이아웃 · 타이포 · 3색 토큰
│  ├─ lib.js, icons.js  이징·글자 맞춤·선 아이콘
│  └─ preview.html      미리보기 플레이어
├─ scripts/
│  ├─ render.mjs        검사 → 오디오 → 캡처 → ffmpeg(BT.709) → 결과 검증 (목소리/음악만 두 버전)
│  ├─ voice.mjs         녹음 디코딩·다듬기·문장 자르기·배치, 말소리 구간 찾기(voice:scan)
│  ├─ audio.mjs         BGM·효과음 합성, 목소리 덕킹 믹스, 라우드니스 맞춤
│  ├─ dsp.mjs           필터·BS.1770 라우드니스·피크 리미터
│  ├─ preview.mjs       미리보기 서버
│  └─ server.mjs        로컬 정적 서버
└─ out/                 mp4 · 스토리보드 · 컨택트 시트
```

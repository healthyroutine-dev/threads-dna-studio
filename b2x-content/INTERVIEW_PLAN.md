# B2X · 대표 인터뷰 기획 — 현장 8편

윤채원 대표님을 한 번 앉혀서 찍고 8편으로 자른다. 말은 한국어, 자막은 스페인어.
**대표님 인터뷰지(구글 설문지):** https://forms.gle/9oUZvWXw2RamphYq6 · 응답은 드라이브의 "B2X 대표 인터뷰지 · 응답" 시트에 쌓인다.

이 문서는 **인터뷰어(리워크 PD)용 진행표**와 **대표님 사전 준비물**을 같이 담는다. 대표님께는 "대표님께 미리 드릴 것" 섹션만 먼저 보내도 된다.

## 1. 인터뷰 방식

- **형식:** 인터뷰어는 화면 밖. 최종 영상에는 질문 없이 **대표님 답만** 나간다.
- **그래서 답은 질문을 다시 넣어 완결된 문장으로.**
  - ✕ "네, 그거는 보통 1,000개예요."
  - ○ "브랜드 최소 주문은 보통 1,000개예요."
  - 첫 촬영 전에 대표님께 이 규칙 하나만 확실히 설명한다.
- **한 답은 20~40초.** 길어지면 끊고 "지금 거 한 문장으로 다시 한 번만요"를 요청한다. 편집에서 쓰는 건 결국 그 한 문장이다.
- **후킹 문장은 따로 받는다.** 각 편 끝에 "첫 문장"을 2~3가지 버전으로 다시 말해 달라고 한다. 아래 표의 후킹 예시를 보여주되, 그대로 읽게 하지 말고 대표님 말투로 바꾸게 한다.
- **숫자는 꼭 말로 받는다.** 자막만으로 처리하면 편집에서 근거가 사라진다. "보통", "꽤" 같은 말이 나오면 "대략 몇 개예요?"로 되묻는다.
- **촬영 순서는 8편 순서와 다르다.** 쉬운 사실 질문부터 시작하고, 감정이 필요한 STORY는 대표님이 카메라에 익숙해진 마지막에 찍는다.

## 4. 편별 인터뷰

각 편: **목표 → 질문 → 꼭 나와야 할 것 → 편집 구조**.
질문의 `→` 는 답이 약할 때 꺼내는 꼬리질문이다.

### 4-1. FOUNDER — 브랜드 아니고 트레이더

**목표:** 30초 안에 "누구인지 · 누구를 위해 · 뭘 해주는지".

질문
1. B2X는 뭐 하는 회사예요? 브랜드 회사예요?
   → 브랜드랑 트레이더는 뭐가 달라요? 셀러 입장에서 그게 왜 중요해요?
2. 주로 어떤 사람들이랑 일하세요? (나라·플랫폼·규모)
   → 제일 작은 고객은 어느 정도 규모예요?
3. 셀러가 B2X를 통하면 구체적으로 뭐가 달라져요? 세 가지만.
4. 왓츠앱 클럽은 뭐예요? 들어오면 매주 뭘 받아요?

꼭 나와야 할 것
- "저는 브랜드가 아니에요. 한국에 있는 여러분의 공급자예요." 계열 한 문장
- 대상: 틱톡샵·아마존·인스타 셀러, 뷰티 인플루언서
- 클럽에서 받는 것 3가지 (예: 주간 소싱 리스트, 샘플, 공동구매)

편집 구조: 후킹("저 브랜드 없어요") → 정체성 → 대상 → 클럽 → CTA

### 4-2. MOQ — 1,000개를 10개로

**목표:** 셀러가 제일 막히는 벽(MOQ)을 숫자로 보여주고, 공동구매로 푸는 구조 설명.

질문
1. 해외 셀러가 한국 브랜드에 직접 연락하면 보통 최소 몇 개를 사라고 해요?
   → 제품마다 달라요? 제일 높았던 건요? 낮은 건요?
2. 브랜드는 왜 그렇게 많이 사라고 해요? 브랜드 입장에서 설명해 주세요.
3. B2X에서는 몇 개부터 살 수 있어요? 그게 어떻게 가능해요?
   → 공동구매는 실제로 어떻게 돌아가요? 주문이 안 모이면 어떻게 돼요?
4. 실제 예를 하나 들어주세요. 어떤 제품을, 혼자 사면 몇 개에 얼마, 공동구매로 10개 사면 개당 얼마.
5. 10개로 시작하면 셀러한테 뭐가 좋아요?

꼭 나와야 할 것
- 실제 MOQ 숫자 범위 (`[ ]`개 ~ `[ ]`개)
- "10개부터" + 가능한 이유 한 문장
- 단가 예시 1개 (제품명은 자막에서 가려도 됨)
- 주문이 안 모였을 때의 처리 (신뢰 포인트)

편집 구조: 후킹("최소 1,000개요? 10개로 하세요") → 왜 1,000개인지 → 공동구매 구조(애니) → 숫자 예시 → CTA

준비: 공동구매 실제 사례 1건의 숫자 (참여 셀러 수, 총 수량, 단가).

### 4-3. SAMPLE — 사기 전에 샘플부터

**목표:** "1개부터 확인하고 산다"는 안심. 샘플 서비스 실제 조건 공개.

질문
1. 처음 연락 오는 셀러한테 제일 먼저 뭘 권하세요?
2. 샘플은 어떻게 신청해요? 몇 개까지, 비용은요, 받기까지 며칠 걸려요?
   → 배송비는 누가 내요? 나중에 주문하면 샘플비 빼주는 게 있어요?
3. 샘플 받으면 셀러가 꼭 확인해야 하는 게 뭐예요? 두세 가지만.
   → 대표님이 실제로 확인하는 순서대로요.
4. 샘플 안 받고 바로 대량으로 샀다가 문제 생긴 경우 보셨어요? 어떤 문제였어요?

꼭 나와야 할 것
- 샘플 조건: 수량·비용·기간·국가 (`[ ]`)
- 샘플 받으면 확인할 것 2~3가지 (제형·향, 포장 상태, 라벨·성분)
- "1,000개 사기 전에 1개부터" 계열 한 문장

편집 구조: 후킹 → 샘플 조건(자막 숫자) → 받으면 확인할 것 → 실패 사례 한 줄 → CTA
B롤: 샘플 박스 포장, 송장, 손등 테스트 (예전 SAMPLES 편 컷을 여기서 B롤로 쓴다)

### 4-4. $500 — 500달러로 시작한다면

**목표:** 막연한 "뭘 사야 하지?"에 대표님의 구체적 답.

질문
1. 셀러가 "500달러밖에 없는데 뭘 사야 해요?" 하면 뭐라고 하세요?
2. 실제로 대표님이라면 지금 뭘 몇 개씩 사겠어요? 제품 들고 하나씩.
   → 왜 그 제품이에요? 왜 그 개수예요?
3. 500달러로 시작할 때 절대 사지 말아야 할 건요?
4. 그걸 팔면 대략 얼마 남아요? (대략이라도)

꼭 나와야 할 것
- 제품 3개 (카테고리·개수·이유 한 줄씩)
- "여러 개 조금씩 vs 하나 많이" 중 대표님 원칙
- 피해야 할 것 한 가지

편집 구조: 후킹("저라면 이 세 개 사요") → 제품 1·2·3 (제품 들고) → 피할 것 → CTA
B롤: 창고에서 그 세 제품 집기, 박스에 담기, `$500` 자막 합계

준비: 제품 3개 실물 + 도매가. 인터뷰 때 대표님 손에 들려 드린다.

### 4-5. MISTAKES — 첫 수입 실수 3가지

**목표:** 대표님이 실제로 본 실수. SAMPLE 편과 겹치지 않게 "샘플 안 받기"는 빼고 받는다.

질문
1. 처음 수입하는 셀러들이 제일 많이 하는 실수가 뭐예요? 세 개만 꼽아주세요.
   → (규제가 안 나오면) 나라별 허가나 등록 때문에 막힌 경우는요?
   → (무게가 안 나오면) 배송비 때문에 손해 본 경우는요?
2. 각 실수마다, 그럼 어떻게 해야 해요? 한 문장으로.
3. 그중에 제일 비싸게 치르는 실수는 뭐예요? 실제 금액이나 사례로.

꼭 나와야 할 것
- 실수 3개 + 각각의 해결 한 문장
- 실제 사례 1개 (금액이나 상황)
- 후보: 규제·등록 확인 안 함 / 배송 무게 계산 안 함 / 한 번에 종류를 너무 많이 삼 / 한국 랭킹만 보고 자기 시장 확인 안 함

편집 구조: 후킹 → 1·2·3 (손가락 숫자 + 자막) → 제일 비싼 실수 사례 → CTA

### 4-6. FAKE — 가짜 공급처 구별법

**목표:** 셀러의 가장 큰 두려움(사기·가품)을 한국 현지인이 풀어준다. B2X를 믿을 이유가 자연스럽게 나온다.

질문
1. 해외 셀러들이 "한국 공급처"한테 속는 경우 많아요? 어떤 식으로요?
   → 가품, 돈만 받고 연락 끊김, 유통기한 임박 제품 같은 거요?
2. 진짜 한국 공급처인지 셀러가 직접 확인하는 방법이 있어요? 두세 가지만.
   → 사업자등록증, 브랜드와의 거래 증빙, 실제 창고 영상 같은 걸 요구해도 돼요?
3. 가격이 너무 싸면 의심해야 해요? 기준이 있어요?
4. B2X는 셀러가 확인할 수 있게 뭘 보여줘요?

꼭 나와야 할 것
- 사기 유형 2~3개
- 셀러가 직접 할 수 있는 확인법 2~3개
- "너무 싸면 의심" 계열 한 문장
- B2X가 보여주는 증빙 (`[ ]`: 사업자등록, 브랜드 거래 증빙, 창고 영상 등 실제 가능한 것만)

편집 구조: 후킹("그 공급처, 진짜 한국 회사 맞아요?") → 사기 유형 → 확인법 1·2·3 → B2X 증빙 → CTA

주의: 특정 업체·플랫폼 이름은 말하지 않게 미리 부탁한다. 나오면 편집에서 묵음 처리한다.

### 4-7. NEVER — 절대 안 파는 제품

**목표:** 반전 후킹. "잘 팔려도 안 판다"는 기준으로 전문가 포지션과 신뢰를 동시에 얻는다.

질문
1. 잘 팔리는 건 아는데 B2X에서는 안 다루는 제품이 있어요?
   → 카테고리라도요. 이유는요?
2. 안 다루는 기준이 뭐예요? (규제 위험, 가품 많음, 반품 많음, 마진 구조 등)
3. 셀러가 그 제품 꼭 팔고 싶다고 하면 뭐라고 하세요?

꼭 나와야 할 것
- 안 파는 제품 또는 카테고리 1~2개 + 이유 (`[ ]`)
- 대표님 기준 한 문장 ("저는 ~한 건 안 떼와요")

편집 구조: 후킹("이건 아무리 잘 팔려도 안 떼와요") → 제품/카테고리 → 이유 → 기준 → CTA

주의: 특정 브랜드를 깎아내리는 표현은 피한다. 카테고리나 "이런 유형"으로 말하게 유도한다.

**예비 FAIL** (이어서 바로 질문)
1. 떼왔는데 생각보다 안 팔렸던 제품 있어요? 몇 개 떼왔고 어떻게 됐어요?
2. 거기서 배운 게 뭐예요? 셀러한테 한 문장으로 알려준다면?
→ 답이 구체적이고 숫자가 나오면 NEVER 대신 FAIL을 8편에 넣는다.

### 4-8. STORY — 이 일을 시작한 이유

**목표:** 해외 셀러가 "이 사람은 나를 안다"고 느끼게. 정보가 아니라 장면과 감정.

질문
1. 무역 일은 언제, 어떻게 시작하셨어요? 그 시작 장면을 하나 떠올려 주세요.
   → 그때 몇 살이었어요? 어디서 뭘 하고 있었어요?
2. 처음에 제일 힘들었던 게 뭐였어요?
3. 해외 셀러를 돕는 일은 언제부터, 왜 하게 됐어요? 계기가 된 셀러나 사건이 있어요?
   → 그 셀러는 지금 어떻게 지내요?
4. 해외 셀러들이 부딪히는 벽이 뭐라고 보세요?
5. 그 셀러들한테 한마디 한다면요?

꼭 나와야 할 것
- 구체적인 장면 1개 (연도, 장소, 사건)
- 계기가 된 셀러/사건 1개 (실명은 빼고)
- 벽 3가지 (언어·MOQ·가짜 공급처 계열이면 다른 편과 연결됨)
- 마무리 한 문장 ("혼자 하지 않게" 계열)

편집 구조: 후킹("[N]년 전엔 저도 몰랐어요") → 시작 장면 → 계기 셀러 → 벽 3개 → 클럽을 만든 이유 → CTA
톤: 느린 컷, 창가 측면 → 마지막 문장에서 정면.

## 6. 대표님께 미리 드릴 것

인터뷰 3일 전까지 아래 숫자와 사례를 받아 두면 촬영 때 막히지 않는다. 숫자는 대략이어도 된다.

| 편 | 준비할 것 |
|---|---|
| MOQ | 한국 브랜드 MOQ 범위, 공동구매 실제 사례 1건 (참여 셀러 수·총 수량·단가) |
| SAMPLE | 샘플 조건: 수량·비용·배송 기간·가능 국가, 샘플비 차감 여부 |
| $500 | 추천 제품 3개 실물 + 도매가 |
| MISTAKES | 직접 본 실수 사례 1개 (금액·상황) |
| FAKE | 셀러에게 보여줄 수 있는 증빙 목록 (사업자등록 등 실제 가능한 것만) |
| NEVER / FAIL | 안 다루는 제품·카테고리와 이유 / 안 팔렸던 제품 사례 |
| STORY | 시작 연도, 계기가 된 셀러·사건 (실명 제외) |
| 공통 | 클럽에서 매주 받는 것 3가지, 왓츠앱 그룹 화면 (이름 블러용) |

대표님께 전할 말 세 가지:
1. 질문은 영상에 안 나가요. 질문을 넣어서 완결된 문장으로 답해주세요.
2. 숫자는 대략이라도 말로 해주세요.
3. 특정 업체·브랜드 이름은 빼고 말해주세요.

## 7. 편집 공통

- 길이 30~40초. 답에서 문장 단위로 잘라 붙인다. 인터뷰어 목소리는 모두 삭제.
- 한국어 말 + 스페인어 자막 (상단 1~2줄 대문자, 숫자는 반드시 자막에).
- 같은 날 찍은 8편이라 배경이 같아도 괜찮다. 대신 편마다 첫 컷의 손 소품이나 앵글을 바꿔서 그리드에서 구분되게 한다.
- CTA 동안 하단에 다음 편 예고 자막(`PRÓXIMO: …`). 편 번호는 쓰지 않는다.

# B2X · 아카데미 큐레이팅 12편 세팅

아카데미 16편 = **큐레이팅 12편**(미국권에서 터진 레퍼런스 영상을 바탕에 깔고 채원 원장이 해설) + **현장스케치 4편**(성수 팝업·올리브영·다이소).

## 1. 메인 포맷: 성공요인 분석 (`K-Beauty que vende`)

> **최종 확정 규칙은 `REEL_RULES.md`** (화면 구역·정지 라벨·자막·핸들·더빙·영상 위치). 아래는 처음 기획안이며, 다른 부분은 `REEL_RULES.md`를 따른다.

예전에 만든 vibers 레퍼런스("틱톡샵 성공 요인 분석 021/100")를 B2X용으로 옮긴 포맷이다.

| # | 요소 | vibers 원본 | B2X |
|---|---|---|---|
| 1 | 시리즈 타이틀 | 성공 요인 분석 021/100 | **K-Beauty que vende 001/100** |
| 2 | 요인 칩 5개 | 한국어 칩 5개 | **스페인어 칩 5개, 말할 때 하나씩 켜짐** |
| 3 | 원본 대사 번역 | 원본 대사 → 한국어 | 그대로 (원본 영어 대사 → **스페인어**) |
| 4 | 바탕 영상 | 잘 팔린 원본 영상 | **K-뷰티 영상 + 크리에이터 표기** |
| 5 | 내레이션 | AI 한국어 내레이션 | **채원 대표 음성(한국어) + 스페인어 자막** |

```
┌──────────────────────────────┐
│ B2X                          │
│ K-Beauty que vende 001/100   │ ← 1 시리즈 타이틀
│ [01 ANTES/DESPUÉS][02 …][03 …]│ ← 2 요인 칩 5개 (지금 말하는 칩만 켜짐)
│ [04 …][05 …]                 │
│ DIÁLOGO ORIGINAL · TRADUCCIÓN│
│ "Ojalá no se agote."         │ ← 3 원본 대사 스페인어 번역
│                              │
│      레퍼런스 영상 (풀)        │ ← 4 바탕 + @크리에이터 · 제품명
│                              │
│   채원 대표 말 → 스페인어 자막   │ ← 5 내레이션 자막 (하단, 크게)
└──────────────────────────────┘
```

- **시리즈 번호 `001/100`** 은 이 큐레이팅 시리즈의 업로드 순서로 매긴다(EP 번호 아님). 100편짜리 장기 시리즈로 열어 두는 것. 24편 납품 뒤에도 같은 틀로 계속 이어갈 수 있다.
- **원장 얼굴(PiP)** 은 선택. 기본은 목소리만, 강조할 때 원형 PiP를 잠깐 띄운다. 대표님이 직접 강의 영상으로 쓸 때는 PiP를 켠다.
- **칩 켜짐 = 해설 순서.** 원장이 요인 하나를 말하면 해당 칩이 켜지고 바탕 영상은 그 요인이 보이는 구간으로 간다.

### 요인 칩 단어장 (스페인어)

편마다 5개를 고른다. 칩은 짧게(1~2단어 + 작은 부제).

| 칩 | 뜻 |
|---|---|
| ANTES / DESPUÉS | 전후 대비 |
| PROCESO REAL | 과정 공개 (컷 없는 시연) |
| USO SIMPLE | 사용 단순화 (한 번에, 한 손으로) |
| SIN MIEDO | 걱정 해소 (자극·트러블·가품) |
| CÓMO COMPRAR | 구매 안내 (링크·코드·가격) |
| RESULTADO PRIMERO | 결과 먼저 |
| COREA LO USA | 한국 신뢰 장치 |
| TEXTURA | 제형 클로즈업 |
| PRECIO | 가격 제시 |
| PROBLEMA → SOLUCIÓN | 문제 제기 후 해결 |
| UNA PREGUNTA | 질문 하나로 댓글 유도 |
| ASMR | 소리 (펌프·뚜껑·바르는 소리) |

### 영상 구조 (30~40초)

| 구간 | 시간 | 화면 | 채원 대표 (한국어) |
|---|---|---|---|
| 훅 | 0–3초 | REF 가장 센 장면 + 숫자 자막(조회수·판매량) | "이 영상 하나로 [N] 팔렸어요." 계열 |
| 시그니처 | 3–5초 | 타이틀 + 칩 5개 꺼진 상태로 등장 | "케이뷰티 아카데미 원장, 채원이에요." |
| 요인 01~05 | 5–30초 | 칩 하나 켜짐 → 해당 REF 구간 재생/정지 | 요인당 한 문장 (약 5초) |
| 셀러 적용 | 30–34초 | 칩 5개 전부 켜짐 | "여러분이 팔 때는 이 다섯 개만 기억하세요." |
| CTA | 34–38초 | | "댓글에 ACADEMY 남겨주세요…" + 하단 `PRÓXIMO` |

**강의용 확장:** 칩 하나당 REF 구간을 더 길게 쓰면 그대로 2~3분 강의 영상이 된다.

### 캡션 구조 (스페인어)

vibers 캡션 구조를 따른다.
1. 첫 줄 훅: "Este video vendió [N] en [기간]." 계열
2. 제품 · @크리에이터 크레딧
3. 성공 요인 5개 요약 (한 줄씩)
4. 추정 판매량·조회수 + **출처·기간** + "추정치이며 실제와 다를 수 있음" 고지
5. CTA: "Comenta ACADEMY…"
6. 시리즈명 + 해시태그 3~5개

## 2. 편집 문법 (대본의 `REF` 지시어)

| 지시어 | 뜻 |
|---|---|
| `REF 0:00–0:03 ▶` | 해당 구간 재생 |
| `REF 0:03 ⏸` | 정지 화면 (해설 동안 멈춤) |
| `REF 0:03 🔍얼굴` | 정지 + 해당 부분 확대 |
| `REF 0:00–0:03 ↻` | 같은 구간 반복 재생 |
| `REF-A / REF-B` | 두 영상 좌우 분할 비교 (EP12·14) |
| `REF 자막 ✕` | 원본에 박힌 자막 가림 |
| `칩 03 ●` | 3번 칩 켜기 |

## 3. 12편에 적용하는 방식

- 터진 영상 분석(EP09~12)은 이 포맷 그대로.
- 나머지 편은 **칩 5개를 그 편의 주제로 바꿔 쓴다.** 예: EP15는 칩 = 체크리스트 5개, EP20은 칩 = 원가 항목 5개, EP22는 칩 = 크리에이터 3명 + 따라 할 점.
- 칩 구성은 아래 편별 기준의 **칩** 줄에 적었다.

## 4. 편별 레퍼런스 기준

공통 조건: 미국권(영어) 틱톡 · K-뷰티 제품 · 최근 12개월 이내 우선 · 세로 영상 · 15~60초 · 제품이 화면에 분명히 보임.

### EP09 · Por qué este video hizo 5M de vistas
- **찾을 영상:** K-뷰티 제품 리뷰·시연 영상, 조회수 **약 500만** (300만~800만). 제목 숫자와 맞아야 한다.
- **칩:** RESULTADO PRIMERO · PROCESO REAL · TEXTURA · SIN MIEDO · UNA PREGUNTA (영상 보고 조정)
- **쪼갤 구간:** 첫 3초 후킹 / 시연 / 결과 / CTA가 분명히 나뉘는 영상.
- **해설 포인트:** 결과를 먼저 보여준다 · 컷 없이 시연한다 · 질문 하나로 댓글을 유도한다.
- **검색어:** `kbeauty review`, `viral korean skincare`, `tiktok made me buy it kbeauty`

### EP10 · El formato glass skin nunca muere
- **찾을 영상:** 글래스 스킨 전후 비교 영상 1개 (메인) + 같은 포맷 2개 (짧게 몽타주).
- **칩:** ANTES / DESPUÉS · LUZ DE VENTANA · MISMO ÁNGULO · UN PRODUCTO · SIN FILTRO
- **쪼갤 구간:** 전 / 바르는 과정 / 후. 조명·각도가 같은지 보이는 영상.
- **해설 포인트:** 창문 빛 정면 · 같은 각도 · 제품 하나 · 필터 티 나면 끝.
- **검색어:** `glass skin before and after`, `glass skin routine`, `korean glass skin`

### EP11 · "La coreana lo prueba primero"
- **찾을 영상:** "한국 사람(피부과·약사·한국인)이 쓰는 것" 신뢰 장치를 쓴 영상.
- **칩:** COREA LO USA · RANKING REAL · RESEÑAS · SIN MENTIR · CÓMO COMPRAR
- **쪼갤 구간:** 신뢰 문장이 나오는 순간 / 근거 화면(랭킹·리뷰).
- **해설 포인트:** 광고보다 사용자 · 한국 랭킹·실제 리뷰로 증명 · 1위 아닌데 1위라고 하지 않기.
- **검색어:** `what koreans actually use`, `korean dermatologist recommends`, `korean pharmacist skincare`

### EP12 · Mismo producto. 2M vs 2K vistas.
- **찾을 영상:** **같은 제품** 영상 2개. REF-A 조회수 높음(100만+), REF-B 낮음(1만 미만).
- **칩:** CARA vs LOGO · PREGUNTA vs HOLA · PRODUCTO 1s vs 10s · RESULTADO · UNA PREGUNTA
- **쪼갤 구간:** 두 영상의 첫 3초를 좌우 분할로.
- **해설 포인트:** 첫 화면(얼굴 vs 로고) · 첫 마디(질문 vs 자기소개) · 제품 등장 시점.
- **찾는 법:** 제품명으로 검색 → 인기순 상위 1개 + 최신순 하위 1개. 후보 제품: `medicube`, `anua`, `beauty of joseon`, `cosrx`, `biodance`, `skin1004`

### EP14 · ¿Moda o básico? No te equivoques
- **찾을 영상:** REF-A 반짝 유행템 영상 1개 + REF-B 스테디셀러 영상 1개 (같은 카테고리면 더 좋음).
- **칩:** ¿RECOMPRA? · CATEGORÍA BÁSICA · ¿TEMPORADA? · ¿UNA MODA? · 70 / 30
- **해설 포인트:** 재구매 · 기본 카테고리 · 시즌·유행 의존. 추천 비율.
- **검색어:** `kbeauty trend`, `viral skincare 2026`, `kbeauty holy grail`, `kbeauty staples`

### EP15 · Mi checklist de 5 antes de comprar
- **찾을 영상:** 틱톡샵에서 잘 팔리는 K-뷰티 제품 영상 1개 (상품 링크가 붙은 영상).
- **칩:** MARGEN ×3 · PESO · INGREDIENTES · RESEÑAS · COMPETENCIA
- **쪼갤 구간:** 제품이 나오는 장면마다 멈추고 체크리스트 5개(마진·무게·성분·리뷰·경쟁)를 하나씩 적용.
- **해설 포인트:** "이 제품, 제 체크리스트로 보면…" 형식. 기준 숫자는 리서치 `creators_sellers.md` EP15 참고, 자막에 "업계 가이드 기준".
- **검색어:** `kbeauty tiktok shop finds`, `tiktok shop korean skincare`

### EP16 · Cada muestra la pruebo yo primero
- **찾을 영상:** 크리에이터가 K-뷰티 제품을 처음 테스트하는 영상 (언박싱·첫 사용).
- **칩:** TEXTURA · EMPAQUE · LOTE Y FECHA · SELLO ORIGINAL · ¿PASA O NO?
- **쪼갤 구간:** 텍스처 / 포장 / 라벨이 보이는 장면.
- **해설 포인트:** "크리에이터는 이걸 보지만, 저는 이것까지 봐요" — 원장의 샘플 검수(누액·배치번호·유통기한·정품 라벨)를 덧붙인다. 마지막에 원장 실제 샘플 테스트 컷 3초.
- **검색어:** `testing viral korean skincare`, `kbeauty first impressions`, `kbeauty unboxing`

### EP18 · Top 3 K-beauty en TikTok Shop hoy
- **찾을 영상:** 미국 틱톡샵 K-뷰티 판매 상위 제품 3개 각각의 대표 영상 (제품별 1개, 짧게).
- **칩:** #3 · #2 · #1 · NO VALE LA PENA · LISTA DEL CLUB
- **쪼갤 구간:** 제품별 2~3초씩 + 원장 10점 판정.
- **해설 포인트:** 셀러 관점 판정 — "잘 팔리지만 이미 셀러가 너무 많다" 같은 이유.
- **찾는 법:** 리서치 결과의 틱톡샵 상위 제품 → 제품명 검색 → 인기순 상위 영상.

### EP19 · Viral en Corea. Aún no en TikTok Shop.
- **찾을 영상:** REF-A 한국 크리에이터가 그 제품을 소개한 영상 (한국 쪽 인기 증거) + 미국 틱톡에서 같은 제품 검색 결과가 적다는 화면 녹화.
- **칩:** VIRAL EN COREA · AÚN NO EN EE.UU. · POR QUÉ EXPLOTÓ · LLEGAR PRIMERO · STOCK
- **해설 포인트:** "한국에선 이만큼 → 미국엔 아직 이만큼" 대비. 먼저 들여오면 가격을 정할 수 있다.
- **주의:** 업로드 직전에 미국 틱톡샵 미입점 다시 확인.

### EP20 · $5 mayorista → $20 retail. Las cuentas.
- **찾을 영상:** 미국 틱톡샵에서 약 $20에 팔리는 K-뷰티 제품 영상 (가격이 화면에 보이는 것).
- **칩:** MAYORISTA · ENVÍO · ARANCEL · COMISIÓN · TE QUEDA
- **쪼갤 구간:** 가격 나오는 장면 정지 → 원장이 원가 계산을 자막으로 쌓아감.
- **해설 포인트:** 도매가 → 배송(우체국 EMS 기준) → 관세 → 틱톡샵 수수료 → 남는 돈. 숫자는 리서치 `creators_sellers.md` EP20, **수수료는 셀러센터에서 확인 후 사용**.

### EP22 · 3 coreanas que debes estudiar
- **찾을 영상:** 한국 크리에이터 3명의 대표 영상 각 1개 (3~5초씩).
- **칩:** CREADORA 1 · CREADORA 2 · CREADORA 3 · QUÉ COPIAR · DÓNDE VERLAS
- **후보:** 리서치 `creators_sellers.md` EP22 — PONY, 이사배, 씬님, Liah Yoo, sunnydahye, Chingu Amiga 중 3명.
- **해설 포인트:** 크리에이터별 스타일 한 줄 + 따라 할 것 하나.

### EP24 · De Corea a TikTok Shop en 6 meses
- **찾을 영상:** 같은 제품의 한국 쪽 초기 영상(REF-A) + 미국에서 터진 영상(REF-B). 두 영상의 게시일 차이가 곧 타임라인.
- **칩:** MES 0 COREA · OLIVE YOUNG · CREADORAS · TIKTOK EE.UU. · TIKTOK SHOP
- **해설 포인트:** 타임라인 자막(한국 출시 → 올리브영 → 한국 크리에이터 → 미국 틱톡 → 틱톡샵). 개월 수는 실제 사례로.
- **찾는 법:** 한국 리서치(`korea.md` EP24)에서 사례 제품 확정 → 양쪽에서 제품명 검색.

## 6. 저작권·운영 원칙

- **틱톡:** 가능하면 앱의 스티치·그린스크린 기능으로 만든다. 플랫폼이 허용하는 재사용 방식이다.
- **인스타그램:** 다른 사람 영상을 내려받아 다시 올리는 것이라 원작자 신고·저작권 차단 위험이 있다. 그래서
  - 출처 `@핸들`을 처음부터 끝까지 표시하고 캡션에도 크레딧을 단다.
  - 원본은 필요한 구간만 짧게 쓰고, 원장 해설이 영상의 중심이 되게 한다(정지·확대·비교로 "분석"임이 보이게).
  - 원본 음악은 빼고 우리 음악을 쓴다.
  - 원작자가 내려달라고 하면 바로 내린다.
- 원작자를 깎아내리지 않는다. EP12의 저조회 영상은 핸들을 가리거나, "이렇게 하면 손해" 예시로만 짧게 쓴다.

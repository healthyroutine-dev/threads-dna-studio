# K-Beauty que vende · 릴스 제작 규칙 (확정 v1)

큐레이팅 릴스는 전부 이 규칙으로 만든다. 기준 샘플: `samples/b2x_kbeauty_que_vende_001_es_dub.mp4` (001/100, 레퍼런스 @kbeautywithelizabeth).
템플릿·빌드 스크립트: `reel-template/` (`python3 build3.py` 한 번으로 완성본이 나온다).

---

## 1. 한 줄 정의

**잘 팔린 K-뷰티 영상을 전체 화면에 깔고, 성공 요인을 말할 때마다 영상을 멈춰 짚어 준다.**
말은 한국어(채원 원장), 화면 글자는 전부 스페인어.

## 3. 요소별 규칙

### 헤더 (항상 표시)
- 배경: 검정 `#0D0D0D` 단색, 높이 575px. 영상 위를 덮는다.
- 1줄: `B2X` 흰 배지 + **K-Beauty que vende** + 분홍 `001/100` (60px, ExtraBold)
- 2줄: `@크리에이터 · 5,36 M de vistas · 57× sus seguidores` (32px, 회색). 스페인어 숫자 표기(소수점 쉼표).
- 요인 칩 5개: `01 PROBLEMA` 형식, 32px. 3개 + 2개 두 줄. 해당 요인을 말한 뒤부터 분홍으로 켜져 끝까지 유지(쌓임).
- 번역 박스: 분홍 세로선 + `TEXTO ORIGINAL · TRADUCCIÓN` + 원본 화면 글자의 스페인어 번역(34px). 원본 장면이 바뀌면 번역도 바뀐다.

### 영상 위치
- 영상은 원본 비율(1080×1920) 그대로, 세로 위치만 `plan.json`의 `video_y`로 영상마다 정한다.
- 정하는 기준 (원본 프레임을 보고):
  1. 숨길 원본 위쪽 글자는 헤더(0–575) 밑으로 들어가게
  2. 얼굴, 특히 눈은 헤더에 걸리지 않게
  3. 원본 하단 자막은 1650 위에서 끝나게
- 빈 곳은 같은 영상을 흐리게 깔아 채운다.
- 001 예: `video_y = 50` ("No filter" 숨김, 눈·하단 자막 보존).

### 정지 구간 (성공 요인 설명)
- 요인 하나를 말할 때 영상을 **멈춘다**. 정지 시간 = 더빙 길이 + 0.45초 (최소 2.6초).
- 화면에는 **분홍 라벨 한 줄만**: `01 · PROBLEMA PRIMERO` (40px, 분홍 배경은 글자 뒤에만). 위치는 헤더 바로 아래 왼쪽(600px).
- **박스·어둡게 하기 금지.** 얼굴을 가리지 않는다.
- 설명 문장은 화면에 쓰지 않는다. 설명은 더빙과 스페인어 자막이 한다.

### 스페인어 자막
- 내용: 한국어 더빙을 스페인어로 옮긴 것. 줄여 쓰되 뜻은 같게.
- 모양: 흰 글씨 54px ExtraBold + 검정 테두리 10px. 배경 없음. 가운데 정렬, 최대 2줄.
- 위치: 원본 하단 자막 **바로 위** (아래 끝 1425px). 원본 자막 위치가 다르면 `subs.html`의 `bottom` 조정.
- 타이밍: `plan.json` 각 정지 구간의 `sub`를 `|`로 끊으면 그 단위로 나눠 말 길이에 비례해 나온다. 한 덩어리는 2줄 안.

### 계정 핸들 (출처 표기)
- `🎥 @크리에이터 · TikTok` 을 **하단 가운데** 처음부터 끝까지 표시 (30px, 흰 글씨 + 검정 테두리).
- `plan.json`의 `handle`.

### 더빙
- 한국어, 채원 원장 목소리. 샘플은 임시 AI 음성(엣지 TTS `ko-KR-SunHiNeural`, +15%) → 정식본은 대표님 녹음으로 교체.
- 문장은 짧게: 요인당 한 문장(3~4초). "하나, …" "둘, …"로 번호를 말한다.
- 첫 정지에서 시그니처: "케이뷰티 아카데미 원장, 채원이에요." + 조회수 + "비결은 다섯 개예요."
- 마지막 정지에서 공식 요약 + CTA: "댓글에 아카데미 남기면 소싱 리스트 보내드려요."
- 배경음악은 넣지 않는다(저작권). 업로드할 때 앱에서 음악을 깐다.

## 4. 영상 흐름 (001 기준, 약 40초)

| 순서 | 화면 | 더빙 |
|---|---|---|
| 재생 ~1초 | 훅 장면 그대로 | — |
| 정지 | `5,36 M DE VISTAS` | 시그니처 + 조회수 |
| 재생 | | — |
| 정지 × 5 | `01 · …` ~ `05 · …` (요인이 보이는 장면에서 멈춤) | 요인 1문장씩 |
| 재생 | 요인 사이 원본 장면 | — |
| 정지 | `LA FÓRMULA` | 공식 요약 + CTA |

- 멈추는 지점 = 그 요인이 화면에 보이는 순간. 장면 전환은 `ffmpeg … select='gt(scene,0.25)'`로 찾는다.
- 원본은 끝까지 다 보여 준다(중간에 자르지 않음).

## 5. 디자인 값

| 항목 | 값 |
|---|---|
| 폰트 | Pretendard (Medium 500 / Bold 700 / ExtraBold 800) |
| 분홍 (강조) | `#FF4F8B` |
| 헤더 배경 | `#0D0D0D` |
| 꺼진 칩 | 테두리 흰색 30%, 배경 `#1A1A1E` |
| 출력 | 1080×1920, 30fps, H.264, AAC 192k, 라우드니스 -16 LUFS |

## 6. 편마다 바꾸는 것 (`reel-template/`)

| 파일 | 바꿀 것 |
|---|---|
| `build3.py` | `SRC` (레퍼런스 영상 파일) |
| `overlay.html` | 시리즈 번호, 크리에이터·조회수·배수 줄, 칩 이름 5개(`L`), 원본 글자 번역(`TR`) |
| `plan.json` | `video_y`, `handle`, 정지 라벨(`cards`), 타임라인(`segs`: 재생 구간·정지 지점), 정지마다 `voice`(한국어)·`sub`(스페인어) |
| `subs.html` | 자막 위치 `bottom` (원본 하단 자막 위치가 다를 때만) |

## 7. 만드는 순서

1. 레퍼런스 확정 (`CURATION.md` 기록표) → 원본 영상 다운로드
2. 프레임 확인: 원본 글자 위치, 얼굴 위치, 장면 전환 시간
3. 성공 요인 5개 정하기 → 칩 이름(스페인어, 짧게)·라벨·더빙·자막 쓰기
4. `video_y`와 정지 지점 정하기
5. `python3 build3.py`
6. 확인: 정지 장면마다 캡처해서 ① 얼굴 안 가림 ② 원본 하단 자막과 우리 자막 안 겹침 ③ 1650 아래 글자 없음 ④ 핸들 보임
7. 스페인어 원어민 검수 → 대표님 녹음으로 더빙 교체 → 최종 렌더

## 8. 하지 말 것

- 영상 위치를 모든 편에 같은 값으로 쓰기
- 1650px 아래(앱 UI 영역)에 글자 두기 (핸들 제외)
- 원본 음악 그대로 쓰기
- 출처 핸들 빼기

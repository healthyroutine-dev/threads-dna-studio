# 근황 썸네일 스튜디오

16:9(1280×720) 유튜브 썸네일 템플릿. `index.html`을 브라우저로 열면 바로 씁니다.

레이어 구성
1. 배경: 공간 사진이나 AI로 만든 배경 (흐림/밝기 조절)
2. 인물: 배경을 지운 PNG (드래그로 위치, 휠로 크기 조절)
3. 텍스트: 손글씨 훅 → 맥락 한 줄 → 메인 감정 단어 (+ 선택 배지)

프리셋: 근황 고백형 / 에세이 고백형 / 대비 충돌형 / 숫자 결과형 / 인물 왼쪽형 / 예능 자막형(비교용).
글꼴 스타일: 모던 고딕(기본) · 에디토리얼 명조 · 예능 자막.
"설정 복사(JSON)"로 스타일을 저장해 두고 다음 영상에서 붙여넣으면 같은 톤으로 시작합니다.

클릭을 부르는 장치 체크리스트
  • 궁금증 공백: 결과는 숨기고 상황만 보여주기. “2년 반”은 말하고, 어떻게 됐는지는 말하지 않기.
  • 대비: 안정(공기업) vs 위험(사업 실패)처럼 두 단어가 부딪히게.
  • 속마음 훅: 손글씨 한 줄은 친구에게 털어놓는 말투로. “썰”, “솔직히”, “…”.
  • 표정이 메인 카피와 같은 감정: 담담한 고백이면 정면 응시, 반전이면 놀란 표정.
  • 한 화면 한 메시지: 글자 크기 3단계(훅 < 맥락 < 메인)만 쓰기.
  • 얼굴은 화면의 30~40%, 시선은 카메라나 글자 쪽.
  • 제목과 겹치지 않게: 제목이 설명이면 썸네일은 감정을 맡기.

# K-Beauty que vende · 편집 규칙 (001·002 기준, 2026-10-24 갱신)

001을 만들면서 정한 규칙. 002부터 그대로 적용한다. 바뀌면 이 파일을 고친다.
기준 결과물: `plan/final/001/` · 도구: `plan/reel001_ceo/` (`beauty.py`, `build_ceo.py`, `build_dub.py`, `el_tts.py`)

## 0. 소통
- **제목은 항상 한국어-스페인어를 같이 적는다.** (예: NI UNA PALABRA. / 5,4 M DE VISTAS. = 말 한마디 없이. / 조회수 540만.)
- 스페인어 문장·캡션을 보여줄 때도 한국어 뜻을 같이 붙인다.
- 영상·자막·로고 어디에도 **B2X 표기 없음**.

## 1. 구성 (B안 · 짧은 버전)
- 편당 **1분 안쪽**, 길어도 65초.
- 멈춤 6~7번: HOOK → 포인트 01·02·03 → 팁 → (판매) → CTA. 멈춤 한 번에 2문장까지.
- **레퍼런스가 재생되는 구간은 원본 소리(음악·효과음·말)를 그대로** 낸다 (원본 전체를 -19 LUFS 정도로 맞춰 대표 음성과 비슷하게). 멈춤 구간은 대표 음성만.
- 원본 레퍼런스: 15초 이하는 전체 재생, 15초 넘으면 멈춤 앞 2.5초씩만 (원본 합계 15초, 늘려도 20초 이하).
- 길이가 모자라면 재촬영 말고 원본 구간을 늘린다.
- 출처 `@계정 · TikTok` 화면 하단에 처음부터 끝까지 + 캡션에 원본 링크.

## 2. 화면
- 포인트 색 `#DB3D5A`, 헤더 배경 `#09090B`, 제목 Archivo Black, 본문·자막 Pretendard ExtraBold, 라벨 Space Mono Bold.
- **헤드카피는 처음 후킹 제목으로 끝까지 고정.** 포인트 이름은 멈춤 배지로 (`❚❚ 01 · SIN FILTRO`).
- 타깃: **페루·남미**. 숫자 표기는 **mil(천)·M(백만)** 으로 통일, K 쓰지 않음. 소수점은 쉼표(5,4 M), 천 단위는 점(2.600) (909 mil = 90만 9천, 5,4 M = 540만). 한국어 뜻도 정확한 숫자로.
- 제목은 스페인어 원어민에게 후킹되는 표현으로 점검 (직역 금지. 예: "0 palabras" → "Ni una palabra").
- 원문 인용이 결정적인 줄은 "EN EL VIDEO «…»" 인용 박스.

## 3. 자막 (스페인어)
- **웬만하면 한 줄**: 54px 기준 폭 900px 이하(약 35자). 실제 폭을 재서 확인.
- 넘으면 의미·호흡 단위로 끊어 다음 조각으로. 두 줄이 꼭 필요하면 의미 단위에서 줄바꿈.
- 원본 영상에 박힌 글자와 겹치면 그 편만 자막을 올린다 (override `sub_bottom`, 기본 495 → 025는 760: 대표 원형 아래·원본 글자 위).
- 타이밍은 스페인어 음성의 단어 시간(whisper word timestamps)에 맞춘다.

## 4. 대표 촬영본
- 파일명/편 번호는 받아쓰기로 확인 (촬영 시 편 시작에 번호를 말함).
- **음성**: highpass 80 → RNNoise(arnndn, sh.rnnn, mix 0.9) → afftdn 약하게 → deesser → 컴프 → -16 LUFS.
- **컷 편집**: 무음 구간 제거, 조각 앞 0.12초·뒤 0.22초 여유 (문장 사이 약 0.3초). 말끝이 잘리지 않게.
- 문장별로 끊어 찍은 촬영본은 이어 붙인 지점이 무음 안에 있는지 확인.
- **원형 화면(PiP)**: 지름 346px(흰 테두리 8px), 위치 x691·y640 / 엔드카드 x367·y220.
  크롭 **900px 고정** (얼굴+손동작). **줌 번갈아 바꾸지 않음** (얼굴 크기 일정).
  멈춤 앞뒤는 첫·끝 프레임으로 채워서 흰 원만 남는 순간 없게.
- **얼굴 보정** (`beauty.py`, K-뷰티 톤): 피부 결 정리+번들거림 감소, 화사한 톤(혈색 유지, 회색·창백 금지),
  광대 아래~턱 V라인(한 번에 부드럽게, 점별 워프 금지), 눈 약 9%, 머릿결 정리·윤기, 바깥 잔머리 정리(얼굴 주변 제외).
  전체 렌더 전에 **전후 비교 사진**을 먼저 보여주고 승인받는다.

## 5. 스페인어 더빙
- 일레븐랩스 **"채원 대표 v2 (원본음성)"** voice_id `2tNk6YiVpK91N5GMnp0a`, 모델 `eleven_multilingual_v2`, 출력 `mp3_44100_128`
  (192k는 Creator 요금제 이상). 키는 Network secrets로 등록되어 요청에 자동으로 붙음.
- 구간별 속도: 스페인어 speed 0.85~1.12로 재생성, 한국어(영상+원음) 최대 1.1배, 남는 차이는 **짧은 쪽을 늦게 시작해 같이 끝나게**.
- 한국어 원음은 -18dB(0.13)로 아래에 깔고, 절대 중간에 자르지 않는다.
- 만든 음성은 스페인어로 다시 받아 적어 대본과 대조 (STT 역검수) + 원어민 1회.
- 이모지는 자막·화면에만, 음성 문장에서는 뺀다.

## 8. 편 번호 · 촬영본
- **편 번호(001~026) = 콘텐츠 순서.** "007편" = 7번째 콘텐츠(판매량 숫자 후킹). 한 편 안의 구간은 HOOK·01~05·CTA로 부른다.
- 촬영본 드라이브 폴더 `10G9sVNDWfjZBGHsHlK3nlDDNG3d-UNhu` (DJI_…_NNNN_D_final.mp4 26개, 편당 1개, 문장 단위로 끊어 찍어 이어 붙임).
  파일↔편 대응은 받아쓰기로 확인: `pipeline/file_map.json` (0014·0022 없음 → 0015=014 … 0028=026).
- 촬영 중 대본과 다르게 말한 문장은 `report.txt`에 ⚠로 표시 → **스페인어는 실제로 말한 문장에 맞춘다.**
- 촬영에서 **포인트를 통째로 건너뛰면** 그 멈춤을 빼고(`drop`) 번호를 실제로 말한 대로 다시 붙인다 (014: 01 건너뜀 → 포인트 2개, 022: 03 건너뜀).
- **같은 말을 두 번** 했으면 하나만 남기고 컷(`cut` 구간, 무음 안에서 자름). 말하다 바꾼 조각도 컷.
- 문장 하나가 빠져 남은 문장이 안 이어지면(021 숫자 문장) 스페인어는 대본대로 두고 메모.
- 받아쓰기 한 조각에 문장 두 개가 묶이면 단어 시간으로 문장마다 쪼개 경계를 잡는다 (`ep.py` 자동).
- 대본 내용이 원본 영상과 사실이 다르면 스페인어·배지에서 바로잡고 메모로 남긴다 (예: 002 "얼굴 없이 손만" → 원본에 얼굴이 나옴 → "Sin hablar · 말 없이 손으로만").

## 9. 더빙 목소리 결정 (2026-10-24)
- "올드하다" 피드백으로 A~D 비교 후 **현재 설정 유지**: multilingual_v2 · stability 0.5 · similarity 0.85 · style 0.15 · speed 구간별 0.85~1.12.

## 10. 자동화 (`plan/pipeline/`)
1. `ep.py prep NNN FILE` 받아쓰기·음성정리·무음·대본 줄 매칭(SECT) → `report.txt`
2. `episodes/NNN/override.json` 작성: `title_es/title_ko`(한 줄 폭 **880 이하** — 넘으면 영상 헤더에서 두 줄로 깨짐, `titles.json`), `thumb_sub_es/ko`, 수정 문장 `es{}`, 배지 `labels{}`, 손본 자막 `subs{}`, `notes`, 경계 `sect{}`, 건너뛴 포인트 `drop[]`, 중복 컷 `cut[[a,b]]`, CTA 자료 `items[]`·`cta_ko`
3. `ep.py plan NNN` → plan_base.json + subs_plan.json (자동 분할 후 **어색한 곳은 손으로 고쳐 override.subs에 저장**)
4. `ep.py tts NNN` 대표 v2 스페인어(속도 1회 추정) + STT 역검수 + 단어 시간
5. `beauty_queue.sh` 얼굴 보정 (원형 영역 960x1000@60,460만, 편당 약 20분) → beauty.mp4, plan crop = [900,30,60]
6. `build_ep.py es|ko` 조립 → `ep_final.py NNN` 썸네일·업로드문구·`plan/final/NNN` (여러 편 한 번에: `build_all.sh NNN ...`)
- 경로는 세션 스크래치패드 기준으로 되어 있음. 새 세션에서는 `S=` 경로만 바꿔서 사용.
